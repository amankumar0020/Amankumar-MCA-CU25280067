# MCA201P Lab Sheet-05 — Complete Solutions

This package contains answers for all 35 programs listed in the uploaded Lab Sheet-05.

## Files
- `MCA201P_AS06_Solutions.py` — complete Python source with Programs 1–35.
- `requirements.txt` — required Python libraries.
- `README.md` — this guide.

## How to run in VS Code
1. Open this folder in VS Code.
2. Open the integrated terminal.
3. Run:
   `pip install -r requirements.txt`
4. Run:
   `python MCA201P_AS06_Solutions.py`

For notebook submission, copy each numbered section into separate Jupyter Notebook cells and add screenshots of outputs/plots as required.

## Important
DQN training can take longer than Q-Learning because it trains a neural network. The supplied code uses a reasonable demonstration setup; for a final lab submission, you can increase the number of episodes if your system can handle it.
