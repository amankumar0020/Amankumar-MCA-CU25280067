# MCA201P-AS11 — Lab Sheet 10
## Capstone Machine Learning Projects

This package contains both projects listed in the supplied assignment:
1. Loan Approval Prediction System
2. Disease Prediction System

### Setup
Python 3.9+ recommended.
```bash
python -m venv venv
# Windows: venv\\Scripts\\activate
# macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
```

### Run Loan Approval
```bash
cd loan_approval
python train.py
streamlit run app.py
```

### Run Disease Prediction
```bash
cd disease_prediction
python train.py
streamlit run app.py
```

### Assignment requirements mapping
- Complete preprocessing: duplicate removal, numeric median imputation, categorical most-frequent imputation, scaling and one-hot encoding for loan data; median imputation for symptom features.
- Compare multiple algorithms: model comparison CSV files generated by each training script.
- Evaluation: accuracy, precision, recall, F1; classification report and confusion matrix.
- Save models: Joblib pipeline files in each `models` folder.
- Prediction interface: Streamlit app for each project.
- Documentation, architecture and flowcharts: included in this folder.
- Presentation: 14-slide PowerPoint in `presentation/`.

### Important dataset limitations
Both included datasets are synthetic educational examples created for demonstrating the required ML workflow. They are not real bank records, official loan outcomes, or medically validated clinical datasets. Replace with instructor-approved, trustworthy datasets if real-world analysis is required. Disease output is not a diagnosis or treatment recommendation.
