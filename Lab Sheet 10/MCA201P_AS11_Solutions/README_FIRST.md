# MCA201P-AS11 — Complete Assignment Package

Open `documentation/README.md` first.

Two projects are included:
- `loan_approval/` — Loan Approval Prediction System
- `disease_prediction/` — Disease Prediction System

Both include source code, datasets, trained `.joblib` models, comparison metrics, classification reports, confusion-matrix images and Streamlit interfaces.

The 14-slide PowerPoint is in `presentation/`.

**Important:** Datasets are synthetic demonstration data. The disease classifier is not a diagnostic tool; the loan classifier is not suitable for real lending decisions. Follow your instructor's dataset requirements before final submission.
