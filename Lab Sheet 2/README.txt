MCA201P LAB SHEET-02 - COMPLETE SOLUTIONS
=============================================

This ZIP contains answers/programs for all 35 questions in Lab Sheet-02:
Lab Assessment of Data Preprocessing.

Files 01-35 correspond directly to Questions 1-35.

Required libraries:
pip install pandas numpy matplotlib seaborn scikit-learn scipy category_encoders

IMPORTANT:
- Replace "data.csv" with your actual dataset filename.
- Some programs use column names such as "Age", "Gender", "Date",
  "First_Name", and "Last_Name". Change these names if your dataset
  uses different column names.
- Question 29 requires category_encoders.
- Questions involving visualizations display plots using Matplotlib/Seaborn.

The programs follow the lab sheet's requested approach:
comments/readability, descriptive variables, copies of the original
dataset, intermediate/final outputs, visualization where applicable,
and saving processed datasets.
